Windows desktop app

Download Mycroscope-Setup.exe

Install this on each Windows computer that should be recorded. The installer asks for the company install key. The person then activates with the code from their invitation.

Download the installer Create the company first

The file is served from this site as downloads/Mycroscope-Setup.exe. Place the current installer in that folder before you publish the site. Until that file is there, the button has nothing to save.

Before you install

  1. An owner creates the organisation and adds the person.
  2. The owner copies the install key from Settings.
  3. The employee acknowledges the monitoring notice after signing in.
  4. Recording follows that notice. Changing what is collected publishes a new notice.
