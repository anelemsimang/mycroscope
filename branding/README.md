# Mycroscope brand kit

The "y" in Mycroscope is a magnifying glass: the handle forms the y's long stroke and descender, the lens sits at
its top. Everything here is generated by `tools/build.mjs` (`cd tools && npm install && npm run build`).
Logos have transparent backgrounds unless they are social banners or app icons.

`preview-brand-kit.png` shows the main versions side by side.

## Which design

| Folder | Design | Use |
| --- | --- | --- |
| `classic` | Lens with a light glint | **Primary logo.** Full set of layouts and sizes |
| `focus` | Lens with a centre dot ("insight") | Alternative |
| `solid` | Tinted lens | Alternative, stands out on busy backgrounds |
| `lens` | Round lens with a short handle | Alternative, more literal magnifier |

## Colour versions (in every folder)

| Suffix | Looks like | Use on |
| --- | --- | --- |
| `-color` | Navy text, cyan glint | White and light backgrounds (default) |
| `-accent` | Navy text, cyan magnifier | Light backgrounds where the magnifier should pop |
| `-reverse` | White text, cyan glint | Navy, dark or photo backgrounds |
| `-black` | All dark ink | Black-and-white printing, fax, stamps, embossing |
| `-white` | All white | Single-colour dark backgrounds, engraving, overlays |

## Layouts

- `horizontal`: the banner logo, for website headers, documents, invoices, email.
- `tagline`: banner logo with "Team activity, transparently." for presentations, flyers and footers.
- `lowercase`: "mycroscope" for informal or product contexts.
- `stacked`: magnifier above the name, for square spaces (stands, merchandise, title slides).
- `icon`: magnifier alone, for small spaces (social posts, stickers, watermarks).
- `app-icons`: rounded app icon, circle avatar (social profile pictures), Android adaptive foreground, splash.
- `favicon`: `favicon.ico` and PNGs for the website, `apple-touch-icon.png`, and `mycroscope-windows.ico`
  (multi-size, for the desktop app and installer).
- `social`: LinkedIn cover, X/Twitter header, Facebook cover, YouTube banner, link-preview image (Open Graph),
  email header and a 16:9 presentation title slide.
- `email`: compact logo for email signatures (use the 600 px file displayed at 300 px wide for sharp results).

Use SVG files wherever possible (website, print, signage): they scale to any size. PNGs come in several widths;
use the largest one that you need, or the 4800 px version for large print.

## Rules

- Keep clear space around the logo of at least the height of the lens on every side.
- Smallest size: horizontal logo 120 px (25 mm) wide; below that use the icon.
- Don't recolour, stretch, rotate, add shadows, or retype the name in another font.
- Don't put the colour logo on mid-tone or busy backgrounds; use `-reverse` or `-white` instead.
